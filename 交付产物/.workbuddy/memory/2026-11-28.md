## 11:25 全面优化新增动物（扁平卡通重做）· commit `62d1102`

用户需求原话：「全面优化这些新增的动物，减少3d渲染，增加角色好看程度，流畅度，保证打字手部按到键盘上，可参考市面上的设计方案，完整的再优化，包括整体比例，外观流畅度，不必要按照原来的方案」。

调研：BongoCat / Shimeji 类主流桌宠是「纯色块 + 黑色轮廓线的扁平 2D 角色 + 爪子按键盘同步敲击」，无 PBR 高光。

技术决策：
- 非猫物种 3D 从 `MeshStandardMaterial` 改为 **`MeshToonMaterial` + 三阶 `DataTexture(NearestFilter)` 赛璐璐**，
  三阶值 `[168,214,255]` 保证浅色动物不发灰；灯光 1.65/2.15 降到 0.78/0.92。
- 新增 `addOutline()` inverted-hull 深色描边（`BackSide` + 外扩 0.024），仅 `max(scale) ≥ 0.30` 的剪影大件加。
- 降渲染负担：球体细分 1280→约 250 三角；`cachedGeometry()` 按参数缓存共享几何（打 `userData.shared`，
  `clearModel()` 跳过 dispose）；去掉无效阴影标记；`setPixelRatio` 1.5→1.35。
- 新增贴纸式扁平接地椭圆阴影。
- **手按键盘**：实测键帽顶面世界 `y=0.183`（`0.015+0.112+0.056`），`SPECIES_ROOT_SCALE=0.9`；
  `frontHand()` 改为按目标掌落点反解 `tilt=atan2(-dz,-dy)`、`reach=hypot(dy,dz)/0.84`，
  旧 `tilt/reach` 入参废弃。原先只有 5 只四足动物有打字手，`buildSpecies()` 末尾按 `hasTypingHands`
  给其余 7 只补手并把贴身小手降级为装饰；`TYPING_HAND_SHOULDER_Y` 按物种给肩线高度。
- 打字动作：`LimbRef` 加 `paw/pawBaseY`，循环只驱动 `arm===true`；掌沿臂方向下压 0.044 + 压扁 0.14，
  整臂只留 0.075 蓄力回旋（旧版整臂旋转会让掌脱键）；手臂半径 `r*1.02→r*1.22`。
