## 11:25 全面优化新增动物（扁平卡通重做）· commit `62d1102`

- 新增贴纸式扁平接地椭圆阴影。

  `frontHand()` 改为按目标掌落点反解 `tilt=atan2(-dz,-dy)`、`reach=hypot(dy,dz)/0.84`，
  旧 `tilt/reach` 入参废弃。原先只有 5 只四足动物有打字手，`buildSpecies()` 末尾按 `hasTypingHands`
  给其余 7 只补手并把贴身小手降级为装饰；`TYPING_HAND_SHOULDER_Y` 按物种给肩线高度。
- 打字动作：`LimbRef` 加 `paw/pawBaseY`，循环只驱动 `arm===true`；掌沿臂方向下压 0.044 + 压扁 0.14，
  整臂只留 0.075 蓄力回旋（旧版整臂旋转会让掌脱键）；手臂半径 `r*1.02→r*1.22`。

## 20:41 修复菜单「检查更新」返回 HTTP 403

实现：
- `updater.rs` 加 `REPO_RELEASES_ATOM`（`github.com/.../releases.atom`），Windows API
  请求补 `X-GitHub-Api-Version`。
- `check_latest_update()` 不再对 API 失败用 `?`：先试 Atom feed 解析最新 tag，
  再兜底「本地版本 + 自有发布页」，永远 `Ok(UpdateInfo)`；降级结果 `downloadUrl=None`。
- `UpdateInfo` 加 `check_degraded: bool`（serde default 兼容旧缓存）；后台 6 小时检查
  跳过降级结果的 available 事件，避免限流时误报新版本。
- `src/main.ts` / `src/menuMain.ts`：降级时给友好提示 + 「打开发布页」；error 阶段
  把 403/429/限流文案统一改掉；独立设置窗口 footer 从 `⚠ Retry` 改为 `↗ 打开发布页`。
- 顺手修 `btnToastOpen` 兜底 URL 原先误指向上游 `qianyiai/KuroCat` 的问题。

坑：
- Atom feed 的 `<title>` 可能是自由文本，不能只靠 `parse_semver(title)`；优先从
  `/tag/vX.Y.Z` link 提取，再加 `extract_version_token()` 扫描 x.y.z。
