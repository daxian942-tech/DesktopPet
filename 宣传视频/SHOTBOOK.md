# DesktopPet 抖音宣传视频 · SHOTBOOK

## §0 风格档 G0

- 画幅：**1080×1920 竖屏**（抖音），30fps，总长 107.5s
- 风格档：DesktopPet 品牌视觉——暖纸底 `#fbf7ef`、柿子橙 `#e56f4f`、鼠尾草绿 `#6f927e`，深墨字 `#2a2521`
- 幕底：`pastel-mesh-flow` 暖纸色慢移（相机极缓推 1.00→1.04）
- 字体气质：圆润无衬线，标题粗、正文常规；两档字重
- 能量档：中（宣传片，钩子与结尾允许到高）
- 字幕：底部居中，整句硬现、无标点，宽 ≤ 900px
- 素材气质：真实 3D 动物渲染图（去背）、GitHub 真页面截图、app 界面截图
- **样板镜：s01**
- 版式节奏：动物特写镜用「素材出血 + 侧边文案」，功能镜用「截图卡 + 标题」，下载镜用「页面截图 + 强调框」；不连续 3 镜同构
